高优先级 — 冗余/重复前端脚本

存在 main.js 与 vue-app.js 的重复逻辑（双重计时器、重复 fetch）。建议合并并删除冗余文件。

中优先级 — CSS 重复/合并

根目录 styles.css 与 css/style.css 重复。已将根文件中的小片段合并到 css/style.css；建议删除根 styles.css。

中优先级 — 运行时数据存储风险

server.js 使用同步 fs 写入 data.json（在仓库根），建议把 data.json 加入 .gitignore（已加入）并考虑迁移到 SQLite/数据库以避免竞态。

低优先级 — 小改进
  • 优化 API_URL 判定逻辑。
  • 使用 Vue ref 替换 document.querySelector 找 file input。
  • 用更友好的 UI 替换 alert/confirm。
